# DSR Mini Competition

Solving this kaggle competition:
https://www.kaggle.com/competitions/favorita-grocery-sales-forecasting/overview

## Setup

* install uv

```
# install dependencies and setup venv
uv sync
```

## Download Data

* make account on kaggle
* generate api token in your profile
* create env file with content:

```
KAGGLE_API_TOKEN=<your_token>
```
